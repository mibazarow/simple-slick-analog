Инструкция по созданию скриншота для README
==============================================

Для создания скриншота screen.png:

1. Откройте index.html в браузере
2. Сделайте скриншот карусели
3. Сохраните как screen.png в корневую папку проекта

Рекомендуемые размеры: 800x400 пикселей
Формат: PNG с прозрачностью

Или используйте инструменты:
- macOS: Cmd+Shift+4 для выделения области
- Windows: Snipping Tool или Win+Shift+S
- Linux: gnome-screenshot или flameshot
